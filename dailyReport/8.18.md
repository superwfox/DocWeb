完成后实际导入了 3 篇公众号文章进行测试，验证了文章解析、AI 分类打标及上传流程，整体鲁棒性测试通过。

三、媒体宣发方案调研
针对媒体宣发模块，对目标平台进行了进一步深度调研，重点核查：
- 各平台 API 能力及开放程度；
- 自动发布的实现条件；
- 国内企业接入及平台审核要求；
- 自动化发布可能涉及的法律与平台合规风险；
- API、账号及第三方服务相关费用。
在实现路径上，确定采用自动化发布 + Fallback 人工发送的双路径方案：能够通过 API 自动完成的平台优先自动发布；无法稳定自动化的平台则保留人工发布流程，优先保证平台覆盖率以及最终内容能够正常发出。
四、客户汲取与海关数据
针对客户汲取第一阶段涉及的海关数据检索进行了重点研究。
目前确认海关数据通常不能只依赖产品名称搜索，更适合采用：
HS 编码 + 英文产品关键词
进行联合检索，以提高目标客户和贸易记录的准确性。
当前已完成产品方向及相关 HS 编码的初步查询，但部分产品存在分类口径和实际出口申报差异，因此暂不直接固化编码。
